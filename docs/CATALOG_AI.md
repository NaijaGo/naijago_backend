# NaijaGo AI catalogue configuration

Set these values only on the backend host (for example, Render Environment). Never put the API key in the admin website or Flutter apps.

```text
GEMINI_API_KEY=<Google AI Studio server API key>
GEMINI_CATALOG_MODEL=gemini-3.6-flash
GEMINI_IMAGE_MODEL=gemini-3.1-flash-image
```

Only `GEMINI_API_KEY` is required. The model variables use the shown defaults.

Generated records are review drafts. An AI-assisted product cannot become active until an admin confirms the real product and supplier, price, physical stock, fulfilment location, specifications, and image rights/accuracy.
